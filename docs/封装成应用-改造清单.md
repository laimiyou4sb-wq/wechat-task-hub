## 二、推荐封装形态

```
微信待办\                       ← 绿色版，整个目录可替换
├─ WeChatTaskHub.exe            ← PyInstaller onedir 入口（--noconsole）
├─ _internal\                   ← Python 运行时 + 依赖（更新时整目录替换）
├─ web\                         ← 前端静态资源（外置，可只更新 UI）
├─ tools\                       ← ngrok.exe / cloudflared.exe（可选，外置）
├─ data\                        ← 首启生成：app.db、日志、pid、tunnel.json
├─ .env                         ← 首启生成：随机 APP_TOKEN 等
└─ 启动说明.txt
```

- **必须 onedir**：onefile 每次启动解压临时目录、数据路径不可控、杀软误报高、没法外置 web。
- 数据与程序分离：**更新 = 替换 exe + `_internal` + `web` + `tools`，`data` 与 `.env` 不动**。
- 旧数据迁移：首启检测旧目录（或提供「导入已有数据」）→ 复制 `data\app.db`、`data\caldav`、`.env`。
- 安装版（可选）：Inno Setup 每用户安装到 `%LOCALAPPDATA%\Programs\微信待办`，数据留在安装目录（可写），卸载保留。

## 三、P0：必须改（约 0.5–1 天）

### 1. 新增 `app/paths.py`（唯一路径事实源）

```python
from __future__ import annotations
import sys
from pathlib import Path

FROZEN = bool(getattr(sys, "frozen", False))
# onedir：exe 在安装目录；_MEIPASS 指向 _internal
APP_DIR = Path(sys.executable).resolve().parent if FROZEN else Path(__file__).resolve().parent.parent
BUNDLE_DIR = Path(getattr(sys, "_MEIPASS", APP_DIR))
DATA_DIR = APP_DIR / "data"
WEB_DIR = APP_DIR / "web" if (APP_DIR / "web").is_dir() else BUNDLE_DIR / "web"
TOOLS_DIR = APP_DIR / "tools"
```

- `config.py`：`BASE_DIR = APP_DIR`；`.env` 读 `APP_DIR/.env`；`data_dir` 默认 `DATA_DIR`；保留 `DATA_DIR`/`DB_PATH`/`ENV_FILE` 环境变量覆盖能力（[config.py:158-168](../app/config.py#L158) 已有）。
- `main.py`：`WEB_DIR` 改从 `app.paths` 取。
- `tunnel.py`：`ROOT = APP_DIR`、`DATA_DIR = APP_DIR/data`、ngrok/cloudflared 默认从 `TOOLS_DIR` 找。
- `launcher.pyw`：`ROOT` 改 `APP_DIR`。

### 2. 入口合并为单 exe（子命令）

| 命令 | 行为 |
|------|------|
| `微信待办.exe` | 默认：确保 WeChatDataAnalysis → 确保服务 → 确保隧道 → 打开浏览器（现有 launcher 逻辑） |
| `--serve` | 真正跑 uvicorn（无窗口子进程，stdout/stderr 重定向到 `data/service.*.log`） |
| `--tunnel` | 跑隧道守护（等价 `tools/tunnel.py`，子命令透传 `--check/--stop/--once`） |
| `--stop` | 停隧道 + 停服务（优雅停止优先） |
| `--no-browser` / `--demo` / `--autostart` | 测试 / 演示 / 开机自启（不弹浏览器） |

实现要点（伪代码）：

```python
def launch_service():
    if getattr(sys, "frozen", False):
        cmd = [sys.executable, "--serve"]
    else:
        cmd = [pythonw_path(), str(APP_DIR / "launcher.pyw"), "--serve"]  # 开发兼容
    subprocess.Popen(cmd, cwd=str(APP_DIR), ..., creationflags=DETACHED_PROCESS | CREATE_NO_WINDOW)
```

`--serve` 分支里 `sys.argv` 只保留 `run.py` 认识的参数，然后 `from app.main import app; uvicorn.run(app, host=..., port=...)`；
`--tunnel` 分支 `from tools.tunnel import main as tunnel_main; tunnel_main(sys.argv[2:])`（需给 `tools/` 加 `__init__.py`）。

### 3. 进程检测与停止

- `pid_is_python(pid)` → `pid_alive(pid)`：`OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION)` + `GetExitCodeProcess`，再 `QueryFullProcessImageNameW` 校验镜像路径是本程序 exe（防 PID 复用误杀）。
- 服务工作进程、隧道守护进程的 pid 文件语义不变，但校验逻辑统一。
- 停止：先调 `POST /api/admin/shutdown`（带 token，`service.stop()` 优雅收尾 + 关 DB），等 2s 再 `taskkill /T /F` 兜底。当前 [launcher.pyw:242](../launcher.pyw#L242) 是直接强杀，SQLite WAL 虽然有保护，但优雅停止更稳。

### 4. 日志与异常兜底

- `--serve` 子进程：`stdout/stderr` 指向 `data/service.out.log` / `service.err.log`（沿用现有约定）。
- 启动器自身异常：写 `data/launcher.log` + MessageBox（已有，保持）。
- `--serve` 里 `logging.basicConfig` 改文件 handler，避免 `sys.stderr is None`。

### 5. 首次运行

- 没有 `.env` 时生成最小配置：`APP_TOKEN=secrets.token_urlsafe(16)`、`PORT=8765`、`DATA_SOURCE=wcda`、`TUNNEL_ENABLED=0`。
- 没有 `data/` 时创建；检测旧项目目录并提示迁移（可选复制）。
- 设置页「手机 App」配对会用新 token，无需用户手抄。

### 6. 打包脚本（新增 `build.ps1` + `requirements-build.txt`）

```powershell
pyinstaller --noconfirm --clean --onedir --noconsole `
  --name WeChatTaskHub --icon assets\wechat-task.ico `
  --version-file build\version_info.txt `
  --add-data "web;web" --add-data "assets;assets" `
  --hidden-import openai --hidden-import brotli `
  --hidden-import tools.tunnel `
  --collect-submodules uvicorn --collect-data tzdata `
  launcher.pyw
```

- onedir 产物 `dist/WeChatTaskHub/`；再把 `web/`、`tools/` 拷到同级，生成 zip。
- 依赖文件：`requirements.txt` + `brotli`、`tzdata`（当前 requirements 没列 brotli；Windows 的 zoneinfo 依赖 tzdata，[config.py:51](../app/config.py#L51) 有兜底但最好显式带上）。
- 构建环境：**建议 python.org 的 3.12/3.13 + venv**；当前机器是 WindowsApps Python 3.13.14，PyInstaller 未安装，Store 版 Python 打包有额外坑，别直接用。

### 7. 版本

- `app/version.py` 单一来源 → `Settings.version`（[config.py:156](../app/config.py#L156)）与 FastAPI `version`（[main.py:259](../app/main.py#L259)）都引用它；`/api/health` 已回传（[service.py:1145](../app/service.py#L1145)），设置页已显示（[settings.js:1050](../web/settings.js#L1050)）。
- 补 `GET /api/version`（版本、构建时间、commit），为后续更新检查铺路。

## 八、风险与注意

1. **onefile 别用**：启动慢、路径不可控、数据易丢、杀软误报。
2. **uvicorn 动态导入**：不 `--collect-submodules uvicorn` 容易出现启动即 `ModuleNotFoundError`（loop/protocol）。
3. **WindowsApps Python 构建坑**：建议独立 venv / python.org 安装包。
4. **中文 exe 名**：建议文件名 ASCII（`WeChatTaskHub.exe`），产品名/快捷方式用中文；版本资源注意编码。
5. **端口/单实例**：现有「健康检查即复用」逻辑保留；`--serve` 前先查端口，避免双进程抢 8765。
6. **数据目录别放 OneDrive/网络盘**：SQLite WAL 会出问题。
7. **`.env` 里的 `APP_TOKEN`**：首启必须随机生成，不能沿用默认 `wechat-tasks`。
8. **升级后前端缓存**：Service Worker 已是 network-first（README 有写），版本号变更时提示刷新。
