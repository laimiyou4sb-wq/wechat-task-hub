## 1. 本次交付

### 1.1 超宽屏占比自适应（用户反馈）
- 1024–1599px：维持 `196 | 1fr | 388`。
- ≥1600px：三栏按视口百分比放大 —— 左导航 `clamp(200, 13vw, 320)`、详情 `clamp(420, 30vw, 780)`、中间列吃剩余。
- ≥2208px：应用整体限宽 2208 并居中（两侧发丝线），避免 2K/4K 下中间列无限拉伸。

| 视口 | 左导航 | 列表 | 详情 | 应用宽 |
|---|---|---|---|---|
| 1024 | 196 | 440 | 388 | 1024 |
| 1440 | 196 | 856 | 388 | 1440 |
| 1600 | 208 | 910 | 480 | 1600 |
| 1920 | 250 | 1092 | 576 | 1920 |
| 2560 | 320 | 1118 | 768 | 2208（居中） |

修复前 2560 下详情栏仅 388（15%），现为 768（30%）。

### 1.2 时间分组
- 今天：逾期（按截止升序置顶）/ 今天 / 待安排；本周：按天（今天 / 明天 / 周X 10月29日）；已完成：今天完成 / 昨天 / 更早；空组不渲染，组头带计数，沿用 `.group` 结构。
- 组头节点与卡片均按 id 增量复用，焦点恢复只落到 `[data-id]` 卡片。

输入框 / 文本域 / 下拉 / contenteditable 聚焦时不触发（Esc 除外）；详情空态显示快捷键提示。

### 1.5 设置页电脑端
- sticky 头部（56px）；两栏 `196 | 1fr`，卡片最大 960；左栏 01–05 分区锚点（LLM / 手机推送 / 消息范围 / 手机同步 / 其余配置），点击平滑定位 + 滚动高亮（aria-current）。
- 未保存提醒：吸底条「有未保存修改 · 保存 / 放弃」，多表单计数；`beforeunload` 确认；保存成功清除；放弃则重新拉取恢复。
- 窄屏单列 + 吸顶；零彩色。

### 1.6 后端 Brotli
- 纯 ASGI `BrotliMiddleware` 包在 `GZipMiddleware` 外层：解析 `Accept-Encoding` q 值（br 优先，`br;q=0.9, gzip;q=1.0` 时选 gzip），命中后把下游请求头收窄为 `br` 避免二次编码。
- 仅压缩文本类型、≥500B、200 响应；304/HEAD/206 不压缩；设置 `content-encoding: br`、修正 `content-length`、补 `vary`，保留 ETag/Last-Modified。
- q11 + MODE_TEXT，压缩放工作线程，按 ETag 做 64 条 LRU 缓存。
- 新增 `tests/test_brotli.py` 17 例。

### 1.7 其它

**本轮修复的三处遗留**
1. **卡片嵌套交互元素**（a11y）：`li[role=button]` 内嵌 `button.task-check` → 改为 `li` 仅作容器，打开动作由内部 `.task-body[role=button][tabindex=0]`（含 `aria-label`）承担，复选框独立；卡片 aria-label 从容器移除，复选框标签带任务名。
2. **「清除」chip 误选中**：清除截止后不再给该动作 chip 加 `is-on`，避免误解为“已选中清除”。
3. **axe 审计发现的 3 类问题**：
   - `region`：`<nav id="rail">` 被 `role="tablist"` 覆盖导致失去地标角色；移动端 `.tabs-wrap` 不在任何 landmark 内 → 桌面 rail 改为普通导航按钮（`aria-current="page"`），移动端 tabs 包进 `<nav>`。
   - `heading-order`：移动端隐藏列表标题后分组 `h3` 跳级 → 分组表头改为 `h2`（与列表标题同级）。
   - `aria-allowed-attr`：`<nav>` 上的 `aria-orientation` 非法 → 移除。
