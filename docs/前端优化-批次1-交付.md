## 1. 本次交付内容

### 1.1 布局与视觉
- **电脑端 ≥1024px**：顶栏 56px + 三栏 `196px / 自适应 / 388px`，全屏铺满、栏间 1px 发丝线；只读/编辑任务详情常驻右栏。
- **白底黑白极简**：全站零彩色。优先级改成「高 / 普通 / 低」黑色描边胶囊；逾期用**左侧黑竖线 + 加粗标题 + 黑点标签**表达；深色模式下自动切换为中性深灰（无彩色）。
- **详情栏 sci-fi 元素**：16px 点阵网格（顶部渐隐）、四角 HUD 括线、底部星轨表盘（刻度环 + 3 条轨道 + 2 颗公转卫星 + 中心核）、等宽铭牌 `TASK · 0042` / `ORBIT · 0042`。全部纯 CSS，`prefers-reduced-motion` 下停止公转。
- **<1024px**：保留原移动布局（顶栏 + 4 tab + 列表 + 底部抽屉 + FAB），仅换成黑白灰；桌面专用元素（rail、详情栏、搜索框、新建按钮）均不出现。

### 1.2 功能
| 功能 | 说明 |
| --- | --- |
| 任务编辑（电脑端） | 右栏「编辑」→ 标题 / 优先级 / 截止（快捷 chips + datetime-local 双向同步）/ 备注；只 PATCH 变更字段，`due_at` 清空发 `""`；保存后列表与详情同步、toast「已保存」、不再全量 GET |
| 已忽略 / 稍后找回 | 左导航新增「已忽略」「稍后」，卡片带「恢复」按钮，PATCH 回 `pending` |
| 5 秒撤销 | 完成 / 忽略 / 稍后均给「撤销」，最多同时 2 条，5s 倒计时条 |
| 增量渲染与焦点 | 按 `data-id` 复用卡片节点；写操作与 60s 轮询不丢焦点；编辑中轮询不覆盖表单 |
| 搜索 | 顶栏搜索，200ms 防抖，按标题/备注/群名跨视图过滤，`/` 聚焦、`Esc` 清空，空结果有提示 |
| 新建 | 桌面「新建任务」与移动 FAB 均可；新增优先级与快捷截止 chips |
| gzip | 服务端 `GZipMiddleware(minimum_size=500)`，HTML/CSS/JS/JSON 全部压缩 |
| notes 可编辑 | `TaskPatch` 支持 `notes`（None=不改、`""`=清空、超长截断 2000） |

## 2. 实测指标（390×844，慢 4G 1.6Mbps / 150ms RTT + 4× CPU 降速）
