## 1. 交付内容

### 1.1 批量选择（仅桌面 ≥1024px）
- 列表头新增「选择」按钮（`aria-pressed` 同步，文案切换为「退出选择」）；进入选择模式后：
  - 每行左侧出现方形复选框，完成圆圈隐藏（防误触）；
  - 点击行 / 复选框切换选中，**Shift + 点击** 按当前可见顺序区间连选；
  - 选中行加浅灰底 + 标题加粗；底部批量条显示「已选 N 项」。
- 批量条动作按视图变化：
  | 视图 | 动作 |
  | --- | --- |
  | 今天 / 本周 / 以后 | 完成、忽略 |
  | 已完成 / 已忽略 / 稍后 | 恢复、删除 |
  | 全部 | 全选、取消 |
- 所有批量请求串行执行，成功后本地合并、重算计数、退出选择模式并 toast（「已批量完成 / 忽略 / 恢复 N 项」「已删除 N 项」）；**删除前二次确认**。
- 切换视图、搜索、新建、打开详情、跨 1024 断点、`Esc` 都会退出选择模式；60s 轮询会剔除已不在当前视图的选中项。

### 1.2 真删除
- 后端新增 `DELETE /api/tasks/{id}`（`require_token` → 成功 `{"ok":true,"id"}`、不存在 404、未鉴权 401），`Database.delete_task()` 物理删除。
- 前端入口：
  - 归档视图（已完成 / 已忽略 / 稍后）详情面板底部新增「删除」（`.btn-danger`，二次确认）；
  - 批量删除（同上二次确认）。
- **CalDAV 联动**：删除只删本机 DB；手机 Tasks.org 侧的 VTODO 由下一次后台同步（默认 ≤30s）自动回收，实测 ICS 从 200 → 404，且不误删其它任务。需要立即回收可调用 `POST /api/caldav/sync`。

## 3. 已知限制

1. **批量删除不可撤销**（仅二次确认）；单条删除同理，无回收站。
2. 手机端暂不提供批量选择与删除入口（约定手机端 UI 单独做）。
3. CalDAV 侧回收最多延迟一个同步周期（默认 30s）；如需即时，可在 DELETE 路由触发同步（1 行改动）。
4. 批量条在选中数 >0 时才出现，因此「全选」需先手动选中 1 条。
5. 进入选择模式不会自动关闭已打开的详情；打开新详情会退出选择。
