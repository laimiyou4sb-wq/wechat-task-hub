# 身份与判定 · 前端契约（batch-identity）

> 本文件由后端实现方维护，前端按此契约实现，不改后端文件。

## 背景

目标是：微信群消息里 **@ 到别人 / 点名指派别人** 的事件不再生成待办；**@ 我 / 直呼我** 的正常生成待办；**没有任何指定对象**的群公告等一切照旧（不得改变原有待办逻辑）。

判定发生在消息进入 LLM/规则提取之前；被判定为「指向他人」的消息直接丢弃，并记入「最近过滤」供复盘。

## 一、设置页新增 API

### 1. GET `/api/settings/identity`

```json
{
  "account": "wxid_xxx",
  "account_source": "auto",
  "data_source": "wcda",
  "filter_enabled": true,
  "fuzzy_enabled": true,
  "manual_names": ["大王"],
  "auto_names": ["001大王", "laimiyou001"],
  "aliases": ["大王", "001大王", "laimiyou001"],
  "ttl_seconds": 600,
  "groups": [
    {
      "session_id": "49777216561@chatroom",
      "group_name": "项目一部4.0",
      "my_nickname": "001大王",
      "members": 14,
      "fetched_at": "2026-10-26T09:20:00",
      "stale": false,
      "error": ""
    }
  ],
  "judgments": {
    "kept_me": 3,
    "kept_all": 1,
    "kept_none": 12,
    "dropped_other": 5,
    "since": "2026-10-26T08:30:00"
  },
  "last_drops": [
    {
      "at": "2026-10-26T09:21:03",
      "group": "祥转老大粉丝群",
      "sender": "417龙嘉杰",
      "targets": ["某某"],
      "content": "@某某 吧唧的好贵"
    }
  ]
}
```

- `account_source`: `auto`（微信自动识别）/ `manual`（设置里手填的 ME_WXID）/ `none`。
- `groups`：只包含已经自动拉取过群成员的群（按群名排序）；`stale=true` 表示缓存已过期，后台会重拉。没有数据时给空数组。
- `judgments`：本次服务启动以来的计数。`last_drops` 最多 20 条，`at` 为本地时间 ISO。
- 该 GET 不改任何状态（不会触发拉取群成员，避免设置页打开很慢）。

### 2. PUT `/api/settings/identity`

请求（所有字段可选，`null`/省略 = 不修改）：

```json
{
  "me_names": ["大王", "老王"],
  "me_wxid": "",
  "identity_filter": true,
  "identity_fuzzy": true
}
```

- `me_names`：手动别名清单（外号、同音/错别字写法都填这里）。字符串数组，自动去空白、逗号分隔也接受（前端统一传数组）。
- `me_wxid`：手填我的 wxid；空字符串表示清除、用自动识别。
- `identity_filter`：是否启用「@/点名指向他人时丢弃」。
- `identity_fuzzy`：是否启用错别字/同音模糊匹配。
- 返回：与 GET 相同的结构，另加 `"persisted": true`；保存后立即生效，无需重启。

### 3. POST `/api/identity/refresh`

请求（可省略 body）：

```json
{ "session_ids": ["49777216561@chatroom"] }
```

- 不传 `session_ids`：刷新我的账号/昵称信息，并重拉当前监控的群（已缓存群 + 置顶群，最多 20 个）。
- 传：同时立刻重拉这些群的成员与我的群昵称。
- 返回：`{"ok": true, "account": "...", "auto_names": [...], "groups": [...], "refreshed": 2}`。
- 该请求可能耗时数秒（取决于群人数），前端按钮要显示 loading 并禁用。

### 4. POST `/api/identity/check`（判定测试框）

请求：

```json
{ "text": "@某某 你去交一下表", "session_id": "54199850704@chatroom" }
```

- `text` 必填；`session_id` 可选（传了就用该群的群昵称/成员表；不传用全局别名）。
- 首次对某个群做判定时，后端会拉一次群成员（可能耗时 1–3 秒）；之后走缓存（`ttl_seconds`）。
- 返回：

```json
{
  "ok": true,
  "text": "...",
  "verdict": {
    "kind": "other",
    "source": "at",
    "reason": "@他人（某某）",
    "targets": ["某某"],
    "matched": ""
  },
  "identity": {
    "session_id": "...",
    "group_name": "祥转老大粉丝群",
    "group_nickname": "001大王",
    "account": "wxid_...",
    "aliases": ["大王", "001大王", "laimiyou001"],
    "members": 42,
    "auto": true
  }
}
```

- `verdict.kind`：`me`（需要我参与，照常建待办）/ `all`（@所有人，照常）/ `other`（指向他人，丢弃）/ `none`（未指定对象，照旧）。
- `verdict.source`：`at`（微信原始 @ 名单）/ `text_at`（正文里的 @ 昵称）/ `vocative`（开头直呼）/ `assign`（“让/请/叫…X”等指派句式）/ `quote`（回复我）/ `none`。

### 5. GET `/api/identity/judgments`

```json
{ "judgments": { "...": 0 }, "last_drops": [ "...同上..." ] }
```

## 二、任务详情新增字段

`GET /api/tasks/{id}` 的 `task` 里新增：

```json
"match_reason": "@我（001大王）"
```

- 可能为空字符串（手动添加、未指定对象、历史任务）。
- 前端在详情「来源」行附近显示「判定依据」，为空时隐藏。
- 桌面端 `buildDetailRead` 与移动端 `renderSheetDetail` 都要显示。

## 三、前端改动范围（只允许改这些文件）

- `web/settings.html`：左侧导航新增「身份与判定」分区（放在「消息范围与白名单」之后、「手机同步」之前），后续分区序号顺延（手机同步 05、其余配置 06）。

**不要修改**：`app/**`、`tests/**`、`.env`、`.env.example`、README/docs（除本契约文件外）。

## 四、UI 要求

1. 顶部摘要：我的账号（wxid，等宽字体）、识别来源（自动/手动/未识别）、自动识别昵称 chips。
2. 「刷新身份」按钮：调 `/api/identity/refresh`，loading 时禁用，完成后 toast + 重新渲染。
3. 手动别名 `textarea`（每行一个），说明：外号、同音字、错别字写法都可以填。
4. 两个开关（checkbox）：
   - 启用「@/点名」过滤（关闭后完全恢复旧逻辑）；
   - 错别字/同音模糊匹配。
5. 各群群昵称表格：群名 / 我的群昵称 / 成员数 / 更新时间 / 状态（正常、已过期、失败）。无数据时显示说明「收到该群消息或点刷新后显示」。
6. 判定测试：`textarea` + 群 `select`（选项来自 `groups`，另有「不指定群」）+ 三个示例填充按钮 + 结果区：
   - 结果用 badge 展示：需要我参与（green）/ @所有人（neutral）/ 指向他人·丢弃（red）/ 未指定（muted）；
   - 展示 `reason`、命中对象 `targets`、群昵称、成员数。
7. 最近过滤：列表显示时间 / 群 / 发送者 / 命中对象 / 原文（单行截断，title 悬浮显示全文）。空态「暂无过滤记录」。
8. 所有请求走现有 `api()`（自动带 token、401 弹授权层）；保存后立即生效并有 toast。
9. 移动端（< 900px）布局不能溢出：表格可横向滚动或改卡片式。

## 五、验收

- 打开设置页，新分区正常加载，无 JS 报错（`node --check web/settings.js`）。
- 手动别名保存后 API 返回包含该别名；关闭过滤后 `filter_enabled=false`。
- 判定测试：`@001大王 明天交表` → `me`；`@某某 你去交一下表`（指定该群 session）→ `other`；`明天下午三点开会` → `none`。
- 任务详情出现「判定依据」行（有值时），手动任务不显示。
