# 手机同步：自研安卓 App（局域网直连 + ngrok 远程）

> **一句话原理**：电脑端把待办存在本机 SQLite，`python run.py` 起的服务对外提供 `/api/app/*` 接口；
> 手机装「微信待办」安卓 App，**在家连同一个 Wi-Fi 时走局域网直连**（`http://192.168.x.x:8765`），
> **在外网时走 ngrok 的固定 HTTPS 域名**（`https://xxx.ngrok-free.dev`，旧版账号为 `.ngrok-free.app`）。
> 两种地址都写在「配对码」里，App 自动选：局域网优先、远程兜底，切换时自动重试。

```
微信消息 ──► 电脑端归纳 ──► data/app.db（SQLite，本机）
                                   │
                                   ▼
                    电脑端服务  127.0.0.1:8765（FastAPI）
                       │                        │
      ┌────────────────┘                        └─────────────────┐
      │ 局域网直连（同一 Wi-Fi）                                    │ ngrok 隧道（外网）
      ▼                                                          ▼
  http://192.168.x.x:8765                          https://xxx.ngrok-free.dev
      │                                                          │
      └──────────────┬───────────────────────────────────────────┘
                     ▼
          手机「微信待办」App（自研安卓，离线可用）
          ├─ 拉增量 /api/app/sync      ├─ 推操作 /api/app/actions
          ├─ 到点提醒（AlarmManager）   └─ 新待办通知
```

> 接口契约见 [APP-SYNC-CONTRACT.md](APP-SYNC-CONTRACT.md)。
> 旧方案（Tasks.org / DAVx5 / CalDAV / Tailscale）**已从代码中移除**，本文只讲自研 App。
>
> 说明：本文不写真实 token / 真实域名。下面的 `wt-xxxxxxxx`、`xxx.ngrok-free.dev` 都是占位符，以你自己电脑上的实际值为准。
> （ngrok 免费账号的固定 dev domain 后缀可能是 **`.ngrok-free.dev`**（新版账号，本机实测：`xxx.ngrok-free.dev`）
> 或 **`.ngrok-free.app`**（旧版），两种现在都常见，具体以 <https://dashboard.ngrok.com/domains> 和 `data/tunnel.json` 为准。）

## 1. 准备

| 需要 | 说明 |
|---|---|
| 电脑端服务 | 桌面「微信待办」双击启动，或 `python run.py` 前台运行；浏览器能打开 `http://127.0.0.1:8765` |
| 安卓 App | 自研 App 安装包（`android/dist/app-debug.apk` 或 `app-release.apk`，由构建产出；也可用 `adb install -r` 装到真机） |
| 网络 | 手机和电脑同一 Wi-Fi（局域网直连）；或电脑能上网（ngrok 远程） |
| ngrok 账号 | 只有远程访问需要；免费注册即可（第 4 节） |

先确认电脑端服务正常（PowerShell）：

```powershell
Invoke-RestMethod "http://127.0.0.1:8765/api/health"
```

返回 `ok : True` 即可。手机 App 的**所有**数据接口都要 `X-Auth-Token`（= `.env` 里的 `APP_TOKEN`），
但正常使用时你不用手输：配对码里已经带上 token 和地址。

## 2. 局域网直连（在家/宿舍，推荐日常使用）

### 2.1 前提：手机和电脑在同一个 Wi-Fi

- 电脑连 Wi-Fi 或手机开热点给电脑连都可以；
- 公司 / 学校 / 酒店网络可能**禁止设备互访**，这种情况用第 4 节的 ngrok；
- 电脑 Windows 防火墙需要放行 **TCP 8765**（仅专用网络）。管理员运行一次
  `.\scripts\install_task.ps1` 会自动加防火墙规则；没加的话手机打不开，见第 6 节排查。

### 2.2 拿到配对码

1. 电脑浏览器打开任务表：`http://127.0.0.1:8765/?token=<APP_TOKEN>`；
2. 点右上角 **⚙** → 找到「**手机 App（直连同步）**」卡片；
3. 卡片里会显示：
   - 一个**配对码**（一长串字母数字，点「复制」）；
   - 若干地址：`lan` 开头的是局域网地址（可能有多条，对应不同网卡），`remote` 开头的是 ngrok 地址（配好远程后才有）；
4. 手机和电脑在同一 Wi-Fi 时，复制配对码即可（远程地址有没有都不影响）。

> 配对码 = `base64url(JSON)`，内容包含 `token` + `endpoints`（lan / remote 地址列表）。它等于「地址 + 密码」二合一，
> **不要发到群里、不要截图外传**；泄露后去设置页换 `APP_TOKEN` 会让旧配对码立刻失效。

### 2.3 在 App 里配对

1. 手机安装并打开「微信待办」App；
2. 首次启动会进「设置 → 配对」页（也可从主页右上角设置进入）；
3. 选 **粘贴配对码**，把电脑上复制的配对码粘进去，点「保存 / 配对」；
4. 点「测试连接」：显示成功即配对完成；
5. 回到任务列表，下拉刷新应能看到电脑上的待办。

> 也支持「手动填地址 + token」：地址填 `http://192.168.x.x:8765`，token 填 `APP_TOKEN`。
> 但配对码会自动带上所有地址，推荐用配对码。
>
> App 里地址切换逻辑（契约 §3）：按 `lan` 优先、`remote` 兜底排序；当前地址连接超时 / 5xx 时自动试下一个，
> 成功后记住该地址。所以在家用局域网、出门自动切 ngrok，不用手动改。

### 2.4 验证

- App 里点「立即同步」，电脑网页新建一条任务，App 下拉刷新能看到；
- 手机上勾选完成，电脑网页里该任务变成「已完成」（App 会推送操作，网络恢复后自动补推）；
- 电脑的 `data/app.db` 是唯一权威数据，App 只是「缓存 + 操作队列」。

---

## 3. App 的日常行为（了解即可）

- **离线可用**：没网也能看缓存、勾选；操作进 outbox，联网后自动推送（幂等，不会重复）。
- **到点提醒**：本地 AlarmManager 定时，不依赖电脑在线；但电脑端新增的待办要同步后才会排提醒。
- **新待办通知**：同步到新任务时汇总通知「新增 N 条待办」。
- **电脑休眠 / 关机 / 断网**：App 里的远程地址连不上 → 显示离线；电脑恢复、隧道重连后自动补同步。
- **App 在后台**：Android 会限制后台联网，建议在系统设置里给 App「自启动」「省电策略→无限制」「精确闹钟」权限（小米/HyperOS 尤其需要）。

## 4. 远程访问：ngrok 固定域名（出门在外）

> 目标：给电脑上的 8765 服务一个**固定的 HTTPS 地址**，手机在任何网络（4G/5G/别人家 Wi-Fi）都能访问。
> 本项目用 ngrok 免费版：**1 个固定 dev domain**、**1GB 流量/月**、**20000 请求/月**，够个人待办用。

### 4.1 注册 ngrok（免费，1 分钟）

1. 打开 <https://dashboard.ngrok.com/signup>，用 GitHub / Google / 邮箱注册（不需要信用卡）；
2. 登录后进入 Dashboard。

### 4.2 复制 authtoken

打开 <https://dashboard.ngrok.com/get-started/your-authtoken>，复制 **Your Authtoken**
（形如 `2abc...XYZ`，一长串；**不要**发到群里/截图外传）。

### 4.3 查看免费固定域名

打开 <https://dashboard.ngrok.com/domains>，免费账号自带 **1 个 dev domain**，
形如 `your-name.ngrok-free.dev`（新版账号）或 `your-name.ngrok-free.app`（旧版），
注册时自动分配、**固定不变**，可以改一次名字。

> 后缀 `.dev` / `.app` 由 ngrok 账号决定，**不要手猜**：不填 `NGROK_DOMAIN`（推荐）时，
> ngrok 会自动用你账号分配的那个固定域名，后缀自然正确；只有显式指定时才需要填。
> 想确认本机实际用的是哪个：看 `data/tunnel.json` 的 `url`，或 `python tools\tunnel.py --check`。

### 4.4 运行配置向导（电脑上，一次性）

在项目目录（`D:\微信通知总结\wechat-task-hub`）打开 PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\ngrok_setup.ps1
```

它会：

1. 检查 `tools\ngrok\ngrok.exe`（没有就自动下载官方 Windows 版）；
2. 让你粘贴 authtoken；
3. 固定域名：**不再交互提问**。有 `-Domain` 参数 / 环境变量 / `.env` 的 `NGROK_DOMAIN` 就用，否则留空（= 自动用账号分配的那个固定 dev domain）；
4. 写 `%LOCALAPPDATA%\ngrok\ngrok.yml`（`version: 3` + authtoken + `tunnels.wxtask` → `127.0.0.1:8765`）；
5. 把 `.env` 的 `TUNNEL_ENABLED` 改成 `1`（旧的反向代理地址会自动清掉 `APP_BASE_URL`）；
6. 可选：做一次真实公网验证（非交互环境用 `-Verify` 参数自动验证）；可选：注册开机自启计划任务（一般**不需要**，双击桌面快捷方式会拉起隧道）。

也可以非交互执行（**推荐写法，不会卡在任何提问**）：

```powershell
# 不带 -Domain：自动用 ngrok 账号分配的固定 dev domain（不用手猜 .dev 还是 .app）
powershell -ExecutionPolicy Bypass -File .\tools\ngrok_setup.ps1 -Authtoken <你的token> -NoTask

# 想顺带做一次真实公网验证：加 -Verify
powershell -ExecutionPolicy Bypass -File .\tools\ngrok_setup.ps1 -Authtoken <你的token> -NoTask -Verify
```

> `-Domain` 只在「显式指定域名」时才用（如 `-Domain your-name.ngrok-free.dev`）；不传就留空，
> 由 ngrok 自动用账号分配的那个固定域名（后缀 `.dev` / `.app` 都不会填错）。
> 非交互环境（脚本调用、无 TTY）不会弹任何提示：缺 token 会立即报错退出，验证/计划任务这类可选项直接跳过。
> 可重复运行：换 token / 换域名时再跑一次即可；旧的 `ngrok.yml` 会先备份成 `ngrok.yml.bak-时间`。
> 不想用计划任务：`powershell -ExecutionPolicy Bypass -File .\tools\ngrok_setup.ps1 -UninstallTask`

### 4.5 启动 / 重启

改过 `.env` 需要重启服务：桌面 **「停止微信待办」** → 再双击 **「微信待办」**。

- 双击「微信待办」时，启动器会**依次**：保证服务健康 → 保证隧道在线（已在线则复用，不重复启动）→ 打开网页；
- 隧道进程是后台隐藏窗口，日志在 `data\tunnel.log`，pid 在 `data\tunnel.pid`；
- 公网地址写在 `data/tunnel.json`，服务端配对接口读它，生成配对码里的 `remote` 地址。

### 4.6 验证远程访问

电脑上（PowerShell）：

```powershell
# 1) 一键状态：依赖/进程/状态文件/本机服务/公网链路
python tools\tunnel.py --check

# 2) 看公网地址（{"url": "https://...", "kind": "ngrok", "updated_at": "..."}）
Get-Content .\data\tunnel.json
```

`--check` 最后一行是「结论：健康」就说明：**电脑 → ngrok → 公网 → 你的电脑** 这条链路已经通了。

也可以直接测公网 health（把地址换成 `tunnel.json` 里的 url）：

```powershell
# Windows PowerShell 5.1 默认可能用 TLS 1.0/1.1，先切到 TLS 1.2
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
Invoke-RestMethod "https://xxx.ngrok-free.dev/api/health" -Headers @{"ngrok-skip-browser-warning"="1"}
```

返回 `ok : True` 即成功。**关键一步**：现在回到电脑网页 ⚙ →「手机 App」卡片，配对码里应该出现
`remote` + `https://xxx.ngrok-free.dev` 的地址；**重新复制配对码**，在 App 里重新配对一次。

> **浏览器警告页是正常的**：免费版 ngrok 会在浏览器 HTML 访问前插一个提示页
> （内容类似 `You are about to visit ... served by ngrok.com` / `ERR_NGROK_6024`，带 **Visit** 按钮；
> HTTP 状态码可能也是 200）。点 **Visit** 即可进入，7 天内同一域名不再提示。
> 这是 ngrok 免费版的反钓鱼机制，**不影响** App / API / `tunnel.py`；
> 本项目 App 和上面的 `Invoke-RestMethod` 示例都带了 `ngrok-skip-browser-warning` 头，会直接跳过该页。

### 4.7 手机在外网使用

- 手机开 4G/5G（或任何别的 Wi-Fi），打开 App，点「立即同步」；
- App 发现局域网地址连不上，会自动切换到 `remote` 的 `https://xxx.ngrok-free.dev`；
- 电脑在家里开着、联网、没休眠，就能同步；电脑关机/断网时 App 显示离线，恢复后自动补。

> 你也可以直接用手机浏览器打开 `https://xxx.ngrok-free.dev/?token=<APP_TOKEN>` 使用网页版任务表
> （添加到主屏幕后像 App 一样用）。注意免费版浏览器首次访问会出现 ngrok 的提示页，点 **Visit** 即可。

### 4.8 手动管理隧道

```powershell
python tools\tunnel.py --check   # 查看状态（健康返回 0，不健康返回 1）
python tools\tunnel.py --once    # 前台调试运行（日志打到控制台，Ctrl+C 退出）
python tools\tunnel.py --stop    # 停止隧道（桌面「停止微信待办」也会一并停止）
```

不想用远程了：`.env` 里 `TUNNEL_ENABLED=0`，重启服务；局域网直连完全不受影响。

## 5. ngrok 免费版的限制与注意

| 项目 | 免费版 | 影响 / 处理 |
|---|---|---|
| 固定域名 | 1 个 dev domain（`xxx.ngrok-free.dev` 或 `xxx.ngrok-free.app`，以账号实际分配为准） | 固定不变；不用每次改配对码 |
| 流量 | **1 GB / 月**（出站） | 待办同步的 JSON 很小，正常用远远够；别用它传大文件/看图片 |
| 请求数 | **20,000 次 / 月** | App 同步 + 心跳，一天几十次也够；`tunnel.py` 心跳每 60 秒 1 次 |
| 在线端点 | 最多 3 个 | 本项目只开 1 个 |
| 浏览器提示页 | 免费版对**浏览器 HTML 访问**插一个 ngrok 提示页 | 点 **Visit** 进入；**API 客户端不受影响**；本项目 App 和 `tunnel.py` 会带 `ngrok-skip-browser-warning` 头跳过 |
| 隧道超时 | 免费端点**没有**空闲超时，可长期在线 | 真正的断线来自电脑休眠/断网/重启；`tunnel.py` 会自动重连 |
| 超额 | 超过额度后 ngrok 拒绝请求 | App 显示离线、网页打不开；下个月自动恢复，或临时改用局域网 |

- 查看用量：<https://dashboard.ngrok.com/usage>（在电脑上登录 ngrok 账号看）。
- 电脑**休眠**会让隧道和服务一起断：待办同步不影响数据安全（电脑端才是权威），但手机在休眠期间只能看缓存。
  可以在 Windows 电源设置里把「睡眠」改成「从不」（台式机）/「接通电源时从不」（笔记本）。
- **电脑靠手机 USB 共享上网 / 手机热点上网时**：电脑的联网依赖手机——**手机断数据、拔 USB、关热点 = 电脑断网 = 隧道断**。
  这时电脑上的服务本身还在跑（局域网/网页仍可用），网络恢复后 `tunnel.py` 会自动重连 ngrok，`data/tunnel.json` 的
  `updated_at` 会重新变新；电脑在外网期间的 App 操作会在恢复后自动补同步。
- 免费版对**浏览器**直接打开公网地址会先显示 ngrok 警告页（点 Visit）；App / API 不受影响（见 4.6 的说明）。
- `data/tunnel.json` 是「当前可用公网地址」的唯一来源；没有这个文件或已过期，配对码里就只有局域网地址。

## 6. 常见问题

### 6.1 手机完全连不上 / App 显示离线

| 现象 | 排查顺序 |
|---|---|
| 局域网也连不上（在家） | ① 手机和电脑是否**同一 Wi-Fi**（有的路由器开了「AP 隔离/访客网络」会禁止互访）；② 电脑服务是否在跑：`http://127.0.0.1:8765/api/health`；③ 防火墙是否放行 TCP 8765（管理员运行 `.\scripts\install_task.ps1`）；④ 配对码里的 `lan` 地址是不是电脑当前的 IP（换网络后 IP 会变 → 回设置页复制新配对码） |
| 网页能打开但 App 连不上 | ① App 里的地址是否带 `http://` 前缀（局域网必须带）；② token 是否和 `.env` 的 `APP_TOKEN` 一致；③ App 是否给了联网权限 |
| 外网连不上 | ① 电脑是否开机、联网、没休眠；② `python tools\tunnel.py --check` 是否「结论：健康」；③ `data\tunnel.json` 是否存在且 `updated_at` 是最近时间；④ 看 `data\tunnel.log` 尾部错误 |
| 刚换过网络 / 路由器重启 | 电脑局域网 IP 可能变了：电脑网页 ⚙ 重新复制配对码，App 里重新粘贴配对 |

### 6.2 token / 配对相关

| 现象 | 处理 |
|---|---|
| App 提示 401 / token 失效 | `.env` 的 `APP_TOKEN` 改过（或换电脑了）→ 回设置页复制新配对码，App 重新配对 |
| 配对码粘贴后提示无效 | 复制时可能漏字符/带空格；重新点「复制」按钮再粘；确认粘贴的是**配对码**而不是 token |
| 手机丢了 / 配对码泄露 | 改 `.env` 的 `APP_TOKEN`（随机长串）→ 重启服务 → 所有旧配对码立即失效 → 手机重新配对 |
| 家里直连正常、出门不行 | 配对码里还没有 `remote` 地址 → 按第 4 节配好 ngrok，重新复制配对码并在 App 里重新配对 |

### 6.3 ngrok / 隧道相关

| 现象 | 原因与处理 |
|---|---|
| `--check` 显示 `authtoken 无效` / 日志有 `ERR_NGROK_105` | authtoken 复制错/失效 → 重新运行 `tools\ngrok_setup.ps1` |
| 日志有 `ERR_NGROK_121` / 会话超限 | 同一账号在别处开了太多 ngrok（免费版并发受限），关掉其它 ngrok 后重启隧道 |
| 提示域名不属于该账号 | `NGROK_DOMAIN` 填的域名不是你账号的 → 到 <https://dashboard.ngrok.com/domains> 复制正确的，或留空让 ngrok 自动用 |
| 4040 端口被占用 | 本机已有别的 ngrok 在跑 → 关掉它；本项目自己的隧道用 `python tools\tunnel.py --check` 查看 |
| `--check` 显示「本机服务不可用」 | 先启动服务（双击桌面「微信待办」），隧道会自动恢复；`tunnel.py` 在本机服务挂掉时不会乱重启隧道 |
| 公网 health 失败但本机正常 | 电脑网络出站被限 / ngrok 额度用完 / ngrok 服务波动 → 看 `data\tunnel.log`，稍等自动重连；局域网仍可用 |
| 电脑重启后外网不通 | 隧道随「微信待办」启动；如果只开了服务没开快捷方式，手动跑一次桌面快捷方式，或 `python tools\tunnel.py --check` 看状态 |
| PowerShell 报「基础连接已经关闭 / 发送时发生错误」 | Windows PowerShell 5.1 的 TLS 问题：先执行 `[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12`，或改用 `curl.exe` |

### 6.4 同步/提醒相关

| 现象 | 处理 |
|---|---|
| 电脑新待办手机没出现 | App 下拉刷新/立即同步；确认配对成功、当前地址可用；电脑端 `counts` 正常 |
| 手机少了一条电脑端新建的待办 / 手机与电脑条数不同 | 旧版同步游标 bug（2026-10-28 已修复：App 误把 `/api/app/actions` 响应的 `cursor` 当作拉取游标，会跳过离线期间电脑端新增任务/删除墓碑的 rev 区间）→ 安装新版 APK（`android/dist/`）；旧版临时在 App 设置里**重新配对**（触发全量同步）即可补回 |
| 手机勾完成，电脑没变 | 等 App 后台推送 or 点「立即同步」；网络恢复后会自动补推（outbox 幂等） |
| 到点不提醒 | 检查 App 通知权限、Android 12+「闹钟和提醒」权限、电池优化（不限制）、任务是否有截止时间 |
| 电脑改了任务，手机显示旧值 | 冲突时服务端优先；App 收到 `stale` 会用服务端最新值刷新，并提示「电脑端已修改」 |

## 7. 安全提示（重要）

- **公网可访问 ≠ 公网可读数据**：任何人拿到你的 `https://xxx.ngrok-free.dev` 域名，只能看到网页外壳；
  所有任务数据接口（`/api/tasks`、`/api/app/*`）都必须带 `X-Auth-Token`，没有正确 token 拿不到数据。
- **但域名 + token 一起泄露就危险**：配对码、token 等于密码，不要发群、不要截图外传；
  觉得泄露了就在 `.env` 改 `APP_TOKEN` 并重启，旧 token 立即失效，手机重新配对即可。
- 本项目只把 **8765 端口**通过 ngrok 暴露出去，不会暴露微信数据目录；电脑端仍是唯一数据源。
- ngrok 免费域名是**你自己账号专属**的固定域名，但**不要把它当成私密地址**（域名本身可能被扫到）。
  App 支持「改 token 后重新配对」就是为这种情况准备的。
- 电脑休眠/断网时手机端显示离线是**预期行为**，恢复后自动补同步，不会丢操作。
- 旧的 CalDAV / Tasks.org / DAVx5 方案已从代码中移除；如果你曾开过，请删除手机上的 DAVx5/Tasks.org 账户。
- 不要把本服务的端口直接暴露到公网（不要做路由器端口映射），远程就用 ngrok。
